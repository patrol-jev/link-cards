# link-cards

**흩어진 링크를 섬네일 한 장씩 카드로 모아 주는 한 장짜리 페이지.**
내가 만든 앱, 자주 쓰는 사이트, 올렸던 글. 주소만 주면 제목 · 설명 · 미리보기 그림을 읽어 카드로 정리하고, 찾기 칸으로 바로 찾습니다.

- 파일 하나(`index.html`)가 전부입니다. 설치할 것도, 서버도 없습니다.
- 코드를 몰라도 됩니다. Claude 에게 링크를 주고 부탁하면 됩니다.

---

## 코드를 몰라도: Claude 에게 부탁하기

### 방법 1. Claude Code (컴퓨터에 설치한 Claude)

1. 이 저장소를 내려받습니다. 초록색 **Code** 단추 → **Download ZIP** → 압축을 풉니다.
2. 그 폴더에서 Claude Code 를 엽니다.
3. 이렇게 말합니다.

```
SKILL.md 대로 내 모아보기를 만들어 줘. 링크는 이거야.
https://내가-만든-앱-1.com
https://내가-만든-앱-2.com
https://내-블로그-글-주소
```

4. 끝나면 `index.html` 을 더블클릭합니다.

### 방법 2. claude.ai 대화창

1. 이 저장소의 `index.html` 과 `SKILL.md` 를 대화창에 올립니다(내려받은 ZIP 안에 있습니다).
2. 「SKILL.md 대로, 이 링크들로 index.html 의 카드 자료를 채워서 파일로 돌려줘」 라고 말하고 링크를 붙입니다.
3. 받은 `index.html` 을 저장하고 더블클릭합니다.

> 대화창에서는 Claude 가 페이지를 직접 못 여는 경우가 있습니다. 그러면 섬네일이 빛깔 카드로 나옵니다. 방법 1 이 더 잘 됩니다.

## 손으로 하기

### 링크 목록으로 채우기 (Node 18 이상)

`links.txt` 에 한 줄에 하나씩 적습니다.

```
https://주소 | 꼬리표1, 꼬리표2 | 직접 적을 한 줄(없으면 페이지 설명)
```

```
node tools/read-links.mjs
```

새 주소만 읽어 붙이고, 이미 있는 카드의 고친 내용은 그대로 둡니다.

### 직접 고치기

`index.html` 맨 아래 `<script id="cards">` 안의 JSON 만 고치면 됩니다. 칸의 뜻은 그 바로 위 주석에 적혀 있습니다.

## 인터넷에 올리기

- **GitHub Pages**: 이 저장소를 내 계정으로 복사(Fork) → **Settings** → **Pages** → Branch 를 `main` 으로 → 저장. 몇 분 뒤 `https://<내 아이디>.github.io/link-cards/` 에 열립니다.
- **아무 정적 호스팅**: `index.html` 한 파일만 올리면 됩니다(갈무리를 썼으면 `thumbs/` 폴더도 같이).

찾는 말은 주소에 붙습니다. `…/index.html?q=사진` 처럼 찾은 화면을 그대로 건넬 수 있습니다.

---

## 알아 둘 것

- 섬네일은 각 페이지가 스스로 내건 미리보기 그림(`og:image`)입니다. 없으면 그 페이지 첫 화면의 갈무리를 `thumbs/` 폴더에 두고 `"image": "thumbs/이름.jpg"` 로 적어도 됩니다. 둘 다 없으면 제목 첫 글자로 빛깔 카드가 됩니다. 그림을 지어내지 않습니다.
- 인터넷에 올릴 때는 `index.html` 과 `thumbs/` 폴더를 같이 올립니다.
- 그림은 원래 사이트에서 바로 불러옵니다. 그 사이트가 그림을 지우거나 막으면 빛깔 카드로 바뀝니다.
- 사내 주소 · `localhost` 는 읽지 않습니다. 공개해도 되는 링크만 넣어 주세요.
